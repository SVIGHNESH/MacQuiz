MacQuiz

A quiz management system for admins, teachers, and students: create subjects and a question bank, assemble quizzes with scheduling and marking schemes, run live or self-paced attempts with grace periods, and review analytics afterward.

FastAPI SQLAlchemy React 19 Vite 7 Tailwind 4 Supabase Postgres JWT auth

Hosting shape

The frontend is a static React SPA on Vercel. The backend is a FastAPI app intended to run as an always-warm process (Render free web service) rather than Vercel serverless functions — see Architecture for why that distinction matters for this app's peak load (a class hitting POST /attempts/start in the same second).
